# AccessAble

AccessAble is an online support and learning website for IT students and alumni. It brings technical help, study guidance, career support, and accessibility resources into one place.

## Why I created it

Learning IT involves more than following lessons. Students can get stuck with software, coding, account access, or finding the right resources. I created AccessAble to help students understand their problem, try a solution, and ask for support when they need more help.

## What the website offers

- **Smart Support Navigator:** Students can search for a problem or answer a few questions to find relevant help.
- **Help Library:** Step-by-step guides cover topics such as Wi-Fi, Python, JavaScript, GitHub, study planning, and job preparation.
- **Practice exercises:** Short activities let students practice networking, Windows, Linux, and programming skills, with feedback on their answers.
- **Support requests:** Students can describe a problem and submit a ticket or request an appointment.
- **My Workspace:** Students can check their requests and see their learning progress.
- **Staff dashboard:** Staff can review requests, add notes, and update their status.

Students can check off guide steps and mark whether a solution worked. If they still need help, they can try another guide or fill out a request form. A reference number appears only after a request is successfully submitted.

## What I used

- **HTML** for the website structure.
- **CSS** for the layout, colors, and responsive design.
- **JavaScript** for navigation, search, interactive guides, exercises, and forms.
- **Supabase** for authentication, storing support requests, and staff access permissions.
- **Browser local storage** for saving learning progress on the same browser.
- **GitHub Pages** for website hosting.

## Learning resources

The website includes links to freeCodeCamp, W3Schools, and Hack The Box Academy so students can continue learning and practicing. These are separate platforms and are not affiliated with AccessAble.

## Project goal

The goal is to give IT students a clear place to start when they need help, while also helping them build the skills to solve problems on their own.
